项目定位

把聊天记录变成可读、可解释、可分享的报告

Cyber Judge 不是云端聊天托管服务，而是一个本地运行的分析工具。它把导入、解析、统计、主题洞察、LLM 报告生成和导出串成一条完整流程，让非技术用户也能从本机数据得到一份结构化报告。

核心能力

从数据导入到最终报告，一次走完

01

本机微信导入

支持准备微信数据、读取会话列表，并按群聊、单聊、全部、日期范围进行筛选。

02

手动 JSON 导入

可上传或粘贴 WeFlow、wechat-decrypt 等工具导出的 JSON，并预览成员、时间范围和样例消息。

03

多模型报告生成

导入页可配置 DeepSeek、OpenAI、通义千问等服务商和模型，API Key 保存在本机配置中。

04

主题洞察页面

覆盖聊天总览、时间与作息、语言与梗、表情包、互动网络、情绪温度、关系走势等模块。

05

桌面版体验

Windows 版将 FastAPI 后端、React 前端和微信导入适配器打包为一个可双击启动的 exe。

06

导出与分享

最终报告支持分享链接、JSON 导出和 HTML 导出，便于保存、复盘或继续加工。

使用流程

四步生成一份聊天分析报告

  1. 选择数据来源 从本机微信导入会话，或上传已有聊天 JSON。
  2. 筛选分析范围 选择群聊或单聊，设置起止日期、报告类型和匿名化选项。
  3. 生成统计与 AI 报告 系统解析消息、计算互动指标，并调用你配置的模型生成最终文本。
  4. 阅读、导出、分享 查看中间主题页和最终报告，按需要导出 JSON 或 HTML。

本地与隐私

敏感数据优先留在你的电脑上

桌面版不会打包 `.env`，LLM API Key 由用户在应用内填写，并保存到本机应用数据目录。

微信导入、解析和数据库默认运行在本地。只有在生成 AI 报告时，才会按你的模型配置调用对应服务商。

发布版 exe 尚未做代码签名，首次运行时 Windows 或杀毒软件可能弹出安全提示。
