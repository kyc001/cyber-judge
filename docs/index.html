报告结构

先给证据，再下判词。

最终报告不是只贴一个总结，而是把统计、原话、互动图谱和 LLM 生成内容分层展示。

01 脱敏预处理

可选择匿名化昵称，报告里保留行为证据，不把隐私直接摆上台面。

02 中间页分层

时间、语言、表情、互动、情绪、消息结构、关系走势逐页拆开。

03 原话支撑

结论旁边保留代表性片段，让锐评有来源，不是凭空嘴硬。

Windows 桌面版

一个 exe，启动本地分析工作台。

桌面版将 FastAPI 后端、React 前端和微信导入适配器打包到一起。用户双击启动后， 在本机完成数据导入、筛选、分析、报告生成和导出。

  • 当前版本：Cyber Judge Desktop v0.1.0
  • 发布附件：CyberJudgeDesktop.exe
  • 文件大小：约 46.5 MB
  • 发布分支：master

本地与隐私

敏感数据优先留在你的电脑上。

不打包密钥

桌面 exe 不包含 `.env`，LLM API Key 由用户在应用内填写并保存在本机应用数据目录。

本地解析

微信导入、聊天解析、统计计算和本地数据库默认运行在用户自己的电脑上。

按需调用模型

只有生成 AI 报告时，才会根据用户配置调用对应 LLM 服务商。
